# My Wealth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace My Trade with My Wealth, a manual THB dashboard for money and investment cash flow.

**Architecture:** Add three RLS-protected Supabase tables, an authenticated My Wealth data layer, and focused client components under the existing dashboard. The dashboard derives daily and monthly net movement from income, paid expenses, and investment opening/closing records without duplicating database entries.

**Tech Stack:** Next.js 16, React 19, TypeScript, Zod, Supabase, Tailwind CSS, shadcn-style UI, Recharts.

**Spec:** `docs/superpowers/specs/2026-08-30-my-wealth-v2-design.md`

## Global Constraints

- All dashboard figures use THB and are manual; do not add provider APIs, live prices, or FX conversion.
- Do not migrate My Trade data, retain My Trade UI, or alter the existing user-deleted `.claude/settings.local.json`.
- Do not add budgets, accounts, balances, transfers, current values, dividends, or editable P&L fields.
- Use RLS and authenticated server-side ownership validation for all new data.
